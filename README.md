# AleXa 7th Debut Anniversary Interactive Card

This version preserves the original multi-stage birthday template: envelope, anniversary cake and wish, growing gift, gift-message stage, pinky promise, and finally the interactive fan-letter list.

## Files
- `index.html`
- `style.css`
- `script-birthday.js`
- `letters.js` (fan submissions)

Keep all four files in the same folder. `letters.js` contains the fan messages collected so far and can be edited to add or correct submissions.

## Publish on GitHub Pages
1. Create a GitHub repository and upload all four files to its root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, and save.
4. Wait for GitHub Pages to provide the public URL.

The page loads `letters.js` as a normal script, so it can be tested by opening `index.html` directly in a browser, and does not require a local web server.
